# Netflix Data Analytics & Power BI Dashboard

## 📌 Project Overview

This project is an end-to-end Data Analytics project based on a Netflix titles dataset containing **8,807 records**.

The project focuses on preparing and transforming the dataset using **Microsoft Excel** and then using **Microsoft Power BI** to create an interactive, multi-page dashboard for analyzing Netflix's content library.

The analysis explores content distribution across movies and TV shows, countries, genres, ratings, release years, directors, and content duration.

---

## 🎯 Project Objective

The main objective of this project is to transform raw Netflix content data into a clean and structured dataset and then develop meaningful visualizations that can help identify trends and patterns in Netflix's content library.

Key objectives include:

- Cleaning and standardizing the raw dataset
- Handling missing and inconsistent values
- Transforming columns into analysis-ready formats
- Creating derived fields for better analysis
- Analyzing Movies vs TV Shows
- Identifying content distribution by country and genre
- Understanding content release trends over time
- Analyzing content ratings and duration
- Building an interactive Power BI dashboard
- Presenting the analysis in a professional and easy-to-understand format

📊 Dataset

The dataset contains 8,807 Netflix titles with information related to movies and TV shows.

Main Columns
Show_ID – Unique identifier for each title
Type – Movie or TV Show
Title – Name of the content
Director – Director of the title
Cast – Cast information
Country – Country information
Primary_Country – Primary country extracted for analysis
Date_Added – Date when the title was added to Netflix
Release_Year – Original release year
Rating – Content rating
Duration_value – Numerical duration value
Duration_type – Duration unit such as minutes or seasons
Original_Genre – Original genre information
Primary_Genre – Primary genre used for analysis
Description – Description of the title
🧹 Data Cleaning & Transformation in Excel

The raw dataset was cleaned and standardized in Microsoft Excel before being used for visualization.

Major data preparation steps included:
Identifying and handling missing values
Standardizing inconsistent values
Handling missing country information
Cleaning date-related fields
Separating duration into numerical value and duration type
Structuring country information for analysis
Creating a primary country field
Structuring genre information for analysis
Creating a primary genre field
Checking the dataset for duplicate and inconsistent records
Standardizing column formats and data types
Preparing the final dataset for Power BI

The final cleaned dataset was then used as the source for dashboard development.

🔎 Key Insights
The dashboard provides several useful observations about the Netflix content library:

Movies represent a larger portion of the Netflix catalog than TV Shows.
The Netflix catalog contains a wide variety of genres, with drama and comedy among the major content categories.
A relatively small number of countries contribute a significant share of the overall content library.
Netflix content expanded significantly during the 2010s.
Content ratings vary considerably across the catalog.
Movie duration varies across genres, with noticeable differences in average runtime.

The dataset contains a large variety of directors and content creators.
